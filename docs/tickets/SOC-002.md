## Decisión y limitaciones

Se cierra como simulación autorizada. La detección del patrón es válida; no se confirma compromiso ni acceso no autorizado. No se aplicó contención ni se realizó un escalado real.

El nuevo control se atribuye a una conexión con journal y Wazuh. La atribución de los cuatro eventos del control histórico permanece separada. La ausencia de `5712` se limita a las consultas y ventanas conservadas. Se incluye el journal original copiado del servidor por SCP y el estado horario de las tres VMs, verificado con `timedatectl`. No se dispone de una exportación completa del índice; `previous_output` inicial está parcialmente visible. La causa del fallo transitorio del indexador no se determinó.
