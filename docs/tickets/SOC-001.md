## Resumen

Se revisaron fallos de autenticación SSH seguidos de un acceso correcto desde el mismo equipo y con la misma cuenta. La actividad corresponde a una prueba autorizada: tres solicitudes de contraseña se respondieron incorrectamente y una nueva conexión se realizó con la contraseña correcta.

## Decisión N1

Se cierra como actividad benigna autorizada. Los eventos examinados representan correctamente un fallo y un acceso correcto. La correlación se realizó manualmente durante el análisis.

No se ha demostrado compromiso de cuenta ni se ha confirmado una alerta correlacionada de fuerza bruta. No se aplicó contención y no se realizó un escalado real.

## Qué motivaría un escalado

Un origen inesperado, un acceso que el usuario niega, actividad posterior sospechosa o falta de contexto suficiente para justificar el cierre. En ese supuesto se entregaría a N2 la cronología, las evidencias y las comprobaciones pendientes.
